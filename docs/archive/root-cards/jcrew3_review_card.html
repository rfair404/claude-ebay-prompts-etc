Description

Original **J.Crew Fall 1995** mail-order clothing catalog — a vintage 1990s issue covering men's and women's apparel and accessories. The cover is dated "Fall 1995" and the interior carries "© 1995 J.Crew, Inc." (catalog code 295 F95/4.2), from the mail-order and toll-free ordering era.

What's Included

  • One (1) J.Crew Fall 1995 clothing catalog (single copy).
  • Directory spans men's suits, shirts, sweaters, outerwear, and footgear plus women's sportswear, knits, skirts, and hosiery — running to p.156.
