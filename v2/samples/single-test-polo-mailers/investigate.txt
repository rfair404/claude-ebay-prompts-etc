## Listing approach recommendation

Lead the title with the specific dating: "Spring 1986 + Fall 1987."
The specificity is a defensible advantage — collectors searching
for a particular Polo RL year or season will find this listing
more reliably when the dates are accurate to the month.

In the description body, present each mailer separately (cover
imagery + season + date code) so a buyer can verify the dating
against the visible-evidence claims. This builds trust and
preempts disputes that arise when a buyer notices a discrepancy
themselves.

Photograph order for the listing:
  1. Front covers side-by-side (photo 1) — hero
  2. Back covers side-by-side (photo 2) — date codes visible
  3. Each back individually with date code clearly readable
     (photos 4 + 5)
  4. Interior spread from each mailer (a SS86 spread + a FW87
     spread) — confirms the seasons
  5. Label-area close-up (photo 3) — establishes that labels were
     removed (head off any "label still attached" expectation)

DO NOT include in the listing:
- "Complete original mailing label intact" (labels are removed)
- Any condition claim about un-photographed interior pages without
  doing the leaf-through first
- Specific value or rarity claims without comp support
