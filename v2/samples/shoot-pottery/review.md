### [1] Cream Stoneware Churn — COLLECTABLE

Sells: $30–$1500+  (best case: late 19th C., named maker + cobalt-blue decoration)

**BUY IF ≤ $15**   ·   stretch ≤ $305 if scenario 1 (named maker + cobalt) verified

⚠ Realistic case (unmarked authentic stoneware, $60–$150) does NOT clear the $100 floor at this buy. Walk away if seller asks > $305 without a verified maker stamp on the hidden side.

Verify (priority order):
  - Rotate the crock and inspect ALL sides for cobalt-blue maker stamp (usually on the shoulder opposite the handle — biggest value driver)
  - Bottom check for impressed maker stamp or gallon number
  - Salt-glaze surface under raking light: orange-peel texture = antique; smooth/uniform = modern repro
  - Weight check: dense and heavy for its size = authentic; lighter than expected = modern repro

Ship: ~8 lb (medium), fragile, USPS Ground ~$18. NOT Media Mail.
Gotcha: Modern Magnolia / Hearth & Hand-style decorative reproductions are visually similar to authentic antique stoneware. Surface texture + weight are the reliable tells.


### [2] Albany-Slip Stoneware Crock — COLLECTABLE

Sells: $25–$400+  (best case: 19th C. American Albany slip, named maker — Norton / Cowden / Whittemore / Hamilton & Jones)

**BUY IF ≤ $13**   ·   stretch ≤ $223 if scenario 1 (named maker) verified

⚠ Realistic case (unmarked 19th C. authentic, $80–$200) only partially clears the floor. Walk away if seller asks > $223 without a verified maker stamp.

Verify (priority order):
  - Bottom inspection for impressed maker stamp (biggest value driver)
  - Interior glaze color: white Bristol slip inside + brown Albany slip outside = authentic 19th C.; uniformly brown inside = modern repro
  - Surface depth under bright light: metallic sheen with slight variation = authentic
  - Tool marks at handle attachment: hand-finished asymmetry = antique

Ship: ~6 lb (medium), fragile, USPS Ground ~$18. NOT Media Mail.
Gotcha: The interior-glaze contrast (white Bristol inside, brown Albany outside) is the single fastest authenticity check — faster than maker-stamp hunting.


### [3] Tall Amphora-Style Pottery Vessel — VINTAGE

Sells: $25–$350  (best case: mid-20th C. Italian or French studio pottery, signed)

**BUY IF ≤ $13**   ·   stretch ≤ $174 if signed maker verified on underside

⚠ Realistic case (unsigned vintage decorator pottery, $40–$100) does NOT clear the $100 floor at this buy point. Walk away if seller asks > $174 without confirming a signature or country-of-origin stamp on the bottom.

Verify (priority order):
  - Flip and photograph the underside — single highest-value check (signature, "Made in Italy" stamp, maker stamp)
  - Glaze under bright light: fine surface crazing = age signal; uniformly perfect = modern
  - Lift it — dense and heavy for its size = hand-thrown studio; light = mass-produced
  - Bottom finish: visible ring marks from a potter's wheel = hand-thrown

Ship: ~10 lb (medium), large/tall, UPS Ground ~$18–$25. NOT Media Mail.
Gotcha: Modern Tuscan-style amphora vessels from home decor retail (HomeGoods, World Market) are extremely common. Without an underside marking confirming Italian/French studio, default expectation is decorator-tier or modern repro.
