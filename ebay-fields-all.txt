Legend:
  REQUIRED  = field is required (aria-required or HTML required attr)
  HIDDEN    = not visible to user (display:none, visibility:hidden, type=hidden, or zero dimensions)
  DISABLED  = field is disabled
  maxLen=N  = maxlength attribute
  PREF      = preference/toggle stored server-side; controls whether optional section is shown

NOTE ON HIDDEN FIELDS:
  eBay's form uses two patterns:
    (A) *Pref checkboxes — server-side toggles that show/hide optional sections.
        These are in the page but hidden from the user; they control whether
        optional features (best offer, scheduling, shipping exclusions, etc.) are displayed.
    (B) Attribute search-box inputs — item-specifics fields rendered as hidden text inputs
        that back the visible tag-select/autocomplete UI.
  Both types are marked HIDDEN below.
